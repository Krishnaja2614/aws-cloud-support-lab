# AWS Cloud Support and Incident Troubleshooting Lab

## Project Overview

A practical cloud support portfolio focused on investigating simulated incidents, identifying root causes, and documenting troubleshooting procedures.

## Objectives

* Investigate common cloud support issues.
* Troubleshoot application errors and access-denied problems.
* Understand AWS networking and connectivity.
* Analyze diagnostic logs and monitoring data.
* Document fixes and preventive actions.

## AWS Services

* Amazon EC2
* Amazon S3
* AWS Identity and Access Management (IAM)
* Amazon VPC
* Amazon CloudWatch

## Incident Scenarios

1. Website HTTP 500 Error
2. IAM Access Denied
3. Network Connectivity Failure
4. Disk Space Exhaustion
5. High CPU Utilization

## Tools

* Visual Studio Code
* Git and GitHub
* Local incident simulations
* AWS documentation

## Project Method

Each incident will include the reported problem, diagnostic evidence, investigation steps, root cause, corrective action, and verification.

## Cost

The initial project uses local simulations and sample evidence. No paid AWS resources are required.

## Status

Project setup completed; incident investigations in progress.
